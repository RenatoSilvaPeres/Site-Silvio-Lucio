# Regras do projeto

- **Commits são do Rafael.** Nunca executar `git commit`, `git push` ou `git init`. Ao terminar, sugerir a mensagem de commit.
- **Uma etapa por vez.** Implementar somente a etapa pedida de [docs/ROADMAP.md](docs/ROADMAP.md), sem adiantar etapas nem juntar duas em um commit. Ao concluir, marcar a etapa no ROADMAP.
- **Verificar antes de sugerir o commit:** `npm run lint` e `npm run test` (quando existirem) e `npm run build`.
- **Dados de exemplo:** ficam em `src/config/` e marcados como exemplo. O site não vai ao ar com textos ou % de economia de exemplo.
- **Idioma:** textos do site e mensagens de commit em português do Brasil.
